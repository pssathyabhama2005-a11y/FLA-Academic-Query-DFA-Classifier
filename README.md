Lexical Analysis DFA Classifier

Project Description

Lexical Analysis DFA Classifier is a Python-based project that uses Deterministic Finite Automata (DFA) for compiler lexical analysis, intent tokenization, and pattern recognition.

Objectives

- To understand Deterministic Finite Automata (DFA).
- To perform lexical analysis.
- To identify and classify input tokens.
- To recognize patterns using automata concepts.

Technologies Used

- Python
- Google Colab
- Jupyter Notebook
- Deterministic Finite Automata (DFA)
